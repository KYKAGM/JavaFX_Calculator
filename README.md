# JavaFX Calculator

Современный калькулятор, выполненный на JavaFX с архитектурой MVC и интерфейсом в стиле iOS.  
Проект разработан с использованием SceneBuilder, включает кастомные элементы и небольшие пасхалки в виде звуковых эффектов при определённых вычислениях.

-----------------------------------------

## Основные возможности
-------------------------
- **Интерфейс в стиле iOS**
  - Округлые кнопки, мягкие цвета, аккуратный минималистичный дизайн.
  - Все элементы созданы через SceneBuilder (FXML).
-------------------------
- **Архитектура MVC**
  - Model: вычисления и обработка данных  
  - View: FXML-интерфейс  
  - Controller: связь логики и UI  
-------------------------
- **Пасхалки (Easter Eggs)**
  - При результате **1889** воспроизводится аудио.
  - При результате **67** открывается отдельное окно с видео.
  - Реализовано через `AudioClip` и `MediaPlayer`.
-------------------------
- **Кастомизированная кнопка 0**
  - Нижняя кнопка “0” имеет отдельный ID для растяжения и уникальной стилизации.
-------------------------
- **Полностью рабочая логика вычислений**
  - Сложение, вычитание, умножение, деление.
  - Смена знака (±)  
  - Проценты (%)  
  - Очистка (AC).
  - Обработка ошибок (деление на ноль, переполнение)  
  - Перетаскиваемое окно (custom undecorated window)

## Как запустить проект
### **1. Запуск через IntelliJ IDEA**

1. Установить Java 17+ и JavaFX SDK.  
2. Открыть проект в IDEA.  
3. В VM Options указать путь к JavaFX (`--module-path` и `--add-modules`)
4. Запустить `CalculatorApp.java`.

### **2. Запуск через JAR-файл**
```bash
java --module-path ./javafx/lib \
     --add-modules javafx.controls,javafx.fxml,javafx.media \
     -jar calculator.jar
```
### **3. Запуск через Maven**
Если используется плагин javafx-maven-plugin:

```bash
mvn clean javafx:run
```
